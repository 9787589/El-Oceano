# OCÉANO — Experiencia web

Experiencia educativa e interactiva sobre los océanos. El sitio funciona directamente en el navegador, sin instalar dependencias ni iniciar un servidor.

## Archivos
- `index.html`: contenido y estructura del sitio.
- `style.css`: diseño y animaciones.
- `script.js`: interacciones, incluida la exploración animada de profundidad.
